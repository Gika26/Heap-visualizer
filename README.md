# Heap Visualizer

Расширение для Visual Studio Code, предназначенное для построения и визуализации бинарных куч.

## Автор
ФИО: Гикавый Александр Максимович  
Группа: М3117

## Описание проекта

Heap Visualizer — плагин, позволяющий работать с бинарными кучами непосредственно в Visual Studio Code.

Расширение поддерживает два типа бинарных куч:
- Max-Heap — максимальный элемент находится в корне.
- Min-Heap — минимальный элемент находится в корне.

## Возможности

- Построение бинарной кучи из массива чисел.
- Добавление новых элементов.
- Удаление корневого элемента.
- Переключение между Max-Heap и Min-Heap.
- Очистка структуры.
- Отображение кучи в виде массива и графического дерева.

## Используемые технологии

- TypeScript
- HTML
- CSS
- Visual Studio Code API

## Архитектура

Основная логика проекта разделена на два модуля:

- `heap.ts` — реализация бинарной кучи и основных алгоритмов.
- `extension.ts` — регистрация команды расширения, создание интерфейса и обработка пользовательских действий.

## Используемые алгоритмы

- `build()` — построение кучи за O(n).
- `siftUp()` — восстановление свойства кучи при движении вверх.
- `siftDown()` — восстановление свойства кучи при движении вниз.
- `insert()` — добавление элемента за O(log n).
- `extractRoot()` — удаление корневого элемента за O(log n).

## Установка

Для сборки проекта необходимо установить Node.js.

В корневой папке проекта выполнить:

```bash
npm install
npm run compile
```

Для создания установочного файла расширения:

```bash
npx --yes @vscode/vsce package
```

Для установки готового расширения использовать команду VS Code `Install from VSIX`.

## Использование

После установки расширения открыть командную палитру VS Code (`Cmd + Shift + P`) и выполнить:

`Heap Visualizer: Open`

В открывшемся окне можно строить и изменять бинарную кучу.
